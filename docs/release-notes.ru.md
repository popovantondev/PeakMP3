# PeakMP3 0.16.0 Preview

## Изменения

Здесь находится самостоятельный проект PeakMP3 0.16.0. Общий установщик остаётся в выпуске YouTubeDownloader 2.6.0; опубликованные архивы не изменены. На сайте доступны три лицензированных фрагмента по 24 секунды с готовыми плотностями 0–10. Файлы посетителей в браузере не обрабатываются. Музыка — CC BY 4.0: [авторы и изменения](../music/CREDITS.md).

## Совместимость

Windows 7 SP1 x86 с SSE2 — обязательная цель; .NET Framework 3.5 / CLR2 с настроенным переходом на CLR4. Подтверждена пользователем работа на Windows 7 и 11; Windows 10 отдельно не проверена. MP3-кодирование может давать истинные пики выше 0 dBTP. Общий установщик размещён в выпуске YouTubeDownloader 2.6.0.

## Установка

Установите общий комплект и запустите PeakMP3. Перетащите аудиофайлы, выберите плотность и сравните A/B. Расширение нужно только для передачи AAC из браузера.
