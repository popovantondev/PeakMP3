# PeakMP3 0.16.0 Preview

## Änderungen

Dies ist das eigenständige Projekt PeakMP3 0.16.0. Das gemeinsame Setup bleibt im Release YouTubeDownloader 2.6.0; veröffentlichte Archive sind unverändert. Die Website bietet drei lizenzierte 24-Sekunden-Ausschnitte mit vorbereiteten Stufen 0–10. Besucherdateien werden nicht im Browser verarbeitet. Musik: CC BY 4.0, siehe [Nachweise](../music/CREDITS.md).

## Kompatibilität

Windows 7 SP1 x86 mit SSE2 ist das Ziel; .NET Framework 3.5 / CLR2 mit CLR4-Fallback. Anwender bestätigt Windows 7 und 11; Windows 10 wurde nicht separat geprüft. MP3-Kodierung kann True Peaks über 0 dBTP erzeugen. Gemeinsames Setup im Release YouTubeDownloader 2.6.0.

## Installation

Gemeinsames Paket installieren und PeakMP3 starten. Audiodateien hineinziehen, Dichte wählen und A/B vergleichen. Die Erweiterung wird nur für AAC aus dem Browser benötigt.
