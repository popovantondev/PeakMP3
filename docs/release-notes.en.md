# PeakMP3 0.16.0 Preview

## Changes

This repository is the development home of PeakMP3 0.16.0. The shared installer remains in YouTubeDownloader 2.6.0; its archives are unchanged. The website has three licensed 24-second examples at prepared densities 0–10. It does not process visitors’ files. Music is CC BY 4.0; see [credits](music/CREDITS.md).

## Compatibility

Targets Windows 7 SP1 x86 with SSE2; .NET Framework 3.5 / CLR2 with CLR4 fallback. User reports Windows 7 and 11 working; Windows 10 was not separately tested. MP3 encoding may produce true peaks above 0 dBTP. Shared installer is hosted in YouTubeDownloader 2.6.0.

## Installation

Install the shared package and open PeakMP3. Drop audio files, choose density and compare A/B. The extension is only needed for browser AAC handoff.
