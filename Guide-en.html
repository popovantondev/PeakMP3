PeakMP3: from source audio to finished MP3

Local audio files work without a browser extension. The installer remains shared with YouTube Downloader.

Installation

  1. Download Setup or extract the complete ZIP. Close PeakMP3 and active downloads before updating.
  2. Run Setup.exe normally. It installs into your user profile without requesting administrator privileges.

Open and process audio

  1. Open PeakMP3 and drop one or more MP3, AAC, WAV or FLAC files onto the track area. Multiple files form a queue.
  2. Choose density: 0 is the original, 1–9 blend in the processed version, and 10 is Maximum. Double-click the knob to enter an integer; negative values attenuate the original, while values above 10 add gain and peak limiting.
  3. Start playback and compare A/B. Seek on the waveform or record; the right fader controls listening volume.
  4. Choose Create MP3 320 and select the destination folder. The save dialog starts on Desktop. Your source file is preserved.

VU calibration

Click the screw below the needle and choose the dBFS reference for 0 VU. This adjusts the display only; it does not change audio processing or the saved file.

Connect YouTube Downloader

Only needed to send AAC from the browser. The shared installer includes Downloader and PeakMP3. In the connection wizard, open the browser extension manager, enable Developer mode and load the indicated extension folder as an unpacked extension. This is optional for local audio files.

%LOCALAPPDATA%\YTWin7_360_MP3\extension

After updates, reload the extension and the YouTube tab. If AAC is not handed over, open the green arrow and check the PeakMP3 connection.

YouTube may require session verification (attestation required). This remains a Preview limitation; playback will not start automatically.

Windows 7 and low-powered PCs

Windows 7 SP1, 32 bit and SSE2 remain the required target. Applications use .NET Framework 3.5 / CLR2 with configured CLR4 fallback on newer Windows. .NET 4.8 and WebView2 are not required. Windows, a compatible browser and system .NET remain prerequisites.

The user reports success on Windows 11 with current Chrome and on Windows 7 with compatible Yandex and Chrome. Exact browser versions and the full set of tested scenarios are not yet recorded. Windows 10 has not been separately tested.

Uninstalling and restoring

Windows uninstall removes the application and integration while retaining user files, settings and audio cache. Remove the extension separately in each browser profile. If a backup exists, Restore_previous.cmd returns to the previous installation.

If something goes wrong

If audio will not open, extract the complete package and check that ffmpeg.exe is beside PeakMP3.exe. Try the source in another player. For save errors, check free space and write access to the destination. Include the PeakMP3 version, Windows version, file format and exact error text in a bug report.
