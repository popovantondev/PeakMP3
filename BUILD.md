# Build PeakMP3

Use Windows with Windows PowerShell and the .NET Framework C# compiler. Supply genuine .NET Framework 3.5 reference assemblies; do not silently substitute modern framework libraries.

```powershell
.\BUILD_PEAK.ps1 -ReferenceDirectory "C:\references\.NETFramework\v3.5"
```

The reference assemblies can be obtained from Microsoft’s `Microsoft.NETFramework.ReferenceAssemblies.net35` NuGet package (1.0.3), under `build/.NETFramework/v3.5`. They are build inputs, not an application runtime.

Output: `PeakMP3/PeakMP3.exe`, x86 CLR2. Keep `PeakMP3.exe.config` and `ASSETS/Vintage/Runtime` beside it. Obtain the reviewed `ffmpeg.exe` and its corresponding-source/license notices from the shared 2.6.0 release, and place it beside the executable. Do not replace an existing public archive with a local build.

Windows 7 SP1 requires the system .NET Framework 3.5/CLR2 and SSE2. CLR4 fallback is configured for modern Windows. A successful compilation does not establish clean-machine compatibility.

The browser demo samples are generated by `tools/RenderAudioDemo.cs` using this engine. `tools/RenderNativeChrome.cs` exports the native controls; neither helper is shipped as an executable. Run `python tools/build_site.py` to regenerate RU/DE/EN pages, then `python tools/check_site.py`.
