PeakMP3: от файла до готового MP3

Локальные аудиофайлы работают без браузерного расширения. Установщик остаётся общим с YouTube Downloader.

Установка

  1. Скачай установщик или распакуй полный ZIP. Перед обновлением закрой PeakMP3 и текущие загрузки.
  2. Запусти Setup.exe обычным способом. Программы устанавливаются в профиль пользователя без запроса прав администратора.

Открытие и обработка аудио

  1. Запусти PeakMP3 и перетащи в область песни один или несколько MP3, AAC, WAV или FLAC. Несколько файлов образуют очередь.
  2. Выбери плотность: 0 — оригинал, 1–9 — смесь с обработанным вариантом, 10 — «Максимум». Двойной щелчок по крутилке открывает ручной ввод целого числа; отрицательные значения уменьшают уровень оригинала, значения выше 10 добавляют усиление и ограничение пиков.
  3. Нажми воспроизведение, сравни A/B. Перемотка доступна по волне и пластинке; фейдер справа меняет громкость прослушивания.
  4. Нажми «Создать MP3 320» и выбери папку сохранения. По умолчанию диалог открывает рабочий стол. Исходный файл сохраняется.

Калибровка VU

Нажми на винт под стрелкой. Выбери уровень dBFS, соответствующий 0 VU. Это настройка индикатора: она не меняет обработку, громкость файла или звук при сохранении.

Подключение к YouTube Downloader

Этот шаг нужен только для передачи AAC из браузера. Общий установщик содержит загрузчик и PeakMP3. В мастере подключения открой страницу расширений браузера, включи режим разработчика и загрузи распакованную папку extension, указанную мастером. Для локальных аудиофайлов этот шаг можно пропустить.

%LOCALAPPDATA%\YTWin7_360_MP3\extension

После обновления перезагрузи расширение и вкладку YouTube. Если AAC не передаётся, открой зелёную стрелку и проверь связь с PeakMP3.

YouTube иногда требует подтверждение сеанса (attestation required). Такой отказ остаётся ограничением Preview; видео автоматически не включается.

Windows 7 и слабые компьютеры

Обязательная цель — Windows 7 SP1, 32 бита и процессор с SSE2. Программы используют .NET Framework 3.5 / CLR2; на новых Windows предусмотрен запуск через CLR4. .NET 4.8 и WebView2 не требуются. Windows, браузер и системная среда .NET устанавливаются отдельно.

Пользователь подтвердил работу комплекта на Windows 11 с актуальным Chrome и Windows 7 с Яндексом и Chrome для этой системы. Точные версии браузеров и полный перечень выполненных сценариев пока не зафиксированы. Windows 10 отдельно не проверена.

Удаление и возврат версии

Удаление через приложения Windows убирает программу и интеграцию, сохраняя пользовательские файлы, настройки и аудиокэш. Расширение удаляется отдельно из каждого профиля браузера. Если имеется резервная копия, Restore_previous.cmd возвращает прежнюю установку.

Если что-то не получилось

Если аудиофайл не открывается, проверь, что комплект полностью распакован и ffmpeg.exe находится рядом с PeakMP3.exe. Попробуй исходный файл в другом проигрывателе. Если не получается сохранить результат, проверь свободное место и доступ к выбранной папке. В сообщении об ошибке укажи версию PeakMP3, Windows, формат файла и точный текст ошибки.
