# PeakMP3

[English](README.md) · [Русский](docs/README.ru.md) · [Deutsch](docs/README.de.md)

Vintage audio controls for Windows 7 SP1 x86 and newer Windows. Choose density, compare A/B, seek on the record and save MP3 320.
