Dies ist das eigenständige Projekt PeakMP3 0.16.0.

## Warum das Setup bei YouTubeDownloader liegt

PeakMP3 und YouTube Downloader werden mit einem gemeinsamen Setup installiert. Dieses Setup liegt im [Release YouTubeDownloader 2.6.0](https://github.com/popovantondev/YouTubeDownloader/releases/tag/v2.6.0), deshalb führt auch der Download-Button von PeakMP3 dorthin. Ein eigenes PeakMP3-Release gibt es nicht; veröffentlichte Archive sind unverändert.

Die Website bietet drei lizenzierte 24-Sekunden-Ausschnitte mit vorbereiteten Stufen 0–10. Besucherdateien werden nicht im Browser verarbeitet. Musik: CC BY 4.0, siehe [Nachweise](music/CREDITS.md).
